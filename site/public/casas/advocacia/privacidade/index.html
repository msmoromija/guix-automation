Privacidade

A Vale Luz Advogados usa os dados que você informa no site para responder seu contato e confirmar a consulta.

Os dados pedidos são nome, telefone, e-mail se você quiser informar, serviço, profissional, dia, horário e a mensagem que você escrever.

Esses dados não são vendidos. Servem para o escritório falar com você pelo WhatsApp ou pelo telefone informado.

Para pedir a exclusão do que foi enviado, chame no WhatsApp do escritório e peça a remoção do contato.
