# Guix

Guix é a marca do site de venda, no domínio que ainda será registrado. Ela não aparece dentro das demonstrações. Cada linha abaixo é um negócio fictício, com prompt próprio e pasta de chegada.

| Nicho | Demonstração | Prompt | Pasta |
| --- | --- | --- | --- |
| Barbearia | Barbearia Vila Norte, Jardins | `prompts/lovable-barbearia.prompt.txt` | `prototipos/barbearia` |
| Salão | Salão Vila Flor, Atalaia | `prompts/lovable-salao.prompt.txt` | `prototipos/salao` |
| Estética | Estúdio Serra Clara, Treze de Julho | `prompts/lovable-estetica.prompt.txt` | `prototipos/estetica` |
| Pet shop | Pet Shop Bento, Grageru | `prompts/lovable-petshop.prompt.txt` | `prototipos/petshop` |
| Academia | Academia Farol, Farolândia | `prompts/lovable-academia.prompt.txt` | `prototipos/academia` |
| Contabilidade | Lima Contabilidade, Centro | `prompts/lovable-contabilidade.prompt.txt` | `prototipos/contabilidade` |
| Advocacia | Vale Luz Advogados, Centro | `prompts/lovable-advocacia.prompt.txt` | `prototipos/advocacia` |

A barbearia já está numa conta do Lovable. Quando o crédito voltar, o botão é Retomar. As outras linhas vão para contas novas, um projeto por conta.

O site da Guix está em `site/`. Fundo claro, marca em texto, e as sete casas apontam para as demonstrações até o código baixado entrar em `prototipos/`. Ele não é um projeto no Lovable. Clínica, dentista e imobiliária ficam de fora deste contrato e entram como módulo próprio.
